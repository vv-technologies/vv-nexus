# VV Nexus Status

This file explains how to read the current state of `vv-nexus`.

It exists to separate:

- active public-facing work
- active internal system work
- transitional structures
- concept or roadmap layers

## Repository Status

`vv-nexus` should currently be read as:

- active core repository
- mixed public and internal system repository
- transitional ecosystem hub while clearer separation continues

It is not a finished product-only repository.
It is the current operational center for multiple VV ecosystem surfaces.

## Status Labels

Use these labels when reading files or areas inside this repository:

### Active

Already part of the working core, visible implementation, or live ecosystem direction.

### Beta

Usable or present as an evolving public-facing surface, but not final.

### Internal

Important to the system or founder workflow, but not meant to be read as a finished public product surface.

### Transitional

Still valuable, but not yet separated cleanly into the final long-term repository or product structure.

### Concept

Important to the ecosystem model or IP logic, but not the same thing as a fully shipped implementation.

### Archived

No longer part of the active public structure.
Kept only for historical reference, recovery, or origin tracking.
